# Модификации и вклад

Сделайте Fork и отдельную ветку, измените файлы в extension. JavaScript выполняется непосредственно из файлов; сборщик и сторонние runtime-библиотеки не нужны.

Проверка: Node.js 22+ → node tests/core.test.cjs. Упаковка: Python 3 → python tools/package.py. Для визуальной проверки загрузите расширение в отдельном профиле браузера. Ожидаемые проверки: поиск, избранное между вкладками, новая форма/ответ, переключение Shorts, отказ/неизвестный результат, восстановление текста, импорт и узкое окно.

Сохраняйте минимальные разрешения и декларацию передачи данных. Не добавляйте аналитику, отправку черновиков на сервер или автоматическую повторную публикацию. Отправку тестового комментария выполняйте только в своём аккаунте и подходящем видео.

Для своего независимого дополнения измените browser_specific_settings.gecko.id. Для обновления исходного проекта сохраните ID и увеличьте version. Если изменилась работа с данными, обновите политику. LICENSE и NOTICE должны оставаться при распространении.

В Pull Request опишите проблему, новое поведение и проведённую проверку. Публикация нового релиза должна опираться на проверенный код; не обещайте совместимость со всеми аккаунтами YouTube.
