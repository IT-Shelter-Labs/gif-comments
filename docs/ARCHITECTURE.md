# Устройство расширения

- src/content.js и content.css — изолированный интерфейс поиска/вложений, библиотека и работа с формами YouTube.
- src/main.js — MAIN-world адаптер. При явном отправлении проверяет одноразовую метку, убирает её и добавляет tenorId в create_comment/create_comment_reply. Страница сохраняет собственную авторизацию. Неподдерживаемые запросы с меткой блокируются, автоматических повторов нет.
- src/sw.js — поиск, разрешение ссылок и рейтинги Tenor, кеш и последовательная очередь сохранения библиотеки. Читает опубликованную JSON-конфигурацию tenor.com и использует содержащиеся там ключи для tenor.googleapis.com; при отказе поиска читает встроенные результаты HTML. Это зависимый от сайта адаптер, а не отдельный зарегистрированный API-клиент. Полученный HTML не исполняется.
- src/shared.js — проверка объектов GIF, локализация и сообщения результата.
- src/popup.* — настройки, импорт/экспорт и резервные черновики.

Запросы поиска идут Tenor; комментарии — YouTube только по действию пользователя. Сведения авторизации YouTube не отправляются Tenor. Библиотека, настройки и черновики локальны. Срок доступности черновиков — 24 часа; истёкшие записи удаляются при обращении к библиотеке/панели.

Изменения внутренних протоколов YouTube и формата Tenor могут потребовать обновления. Переписывание формулировок не устраняет зависимость от этих сервисов.
